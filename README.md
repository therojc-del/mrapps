# Therojc Apps

App presentation, preview download and privacy-policy files for GitHub Pages.

## Enable the public website

GitHub currently reports that this repository does not have an enabled Pages site.
In [Settings → Pages](https://github.com/therojc-del/mrapps/settings/pages), select
**Deploy from a branch → main → /(root) → Save**.
This requires repository administration access. The connected integration can
update repository files but cannot enable this setting.

The prepared website addresses, after Pages is enabled, are:

- [Apps](https://therojc-del.github.io/mrapps/)
- [CutBack 2.8.0 preview](https://therojc-del.github.io/mrapps/cutback/)
- [CutBack privacy policy](https://therojc-del.github.io/mrapps/cutback/privacy.html)

CutBack is a test preview, not a Google Play production release. It uses sample
ads and has no configured real purchases. Its native 2.8.0 screenshots use
sample data. The presentation supports English and Slovenian and horizontal
screenshot navigation on mobile. No website advertising or analytics scripts
are included. The app's interface supports 32 language options.

The existing `privacy.html` and `app-ads.txt` remain at their original paths.
No CutBack source archive, signing credentials or private QA files are published.
